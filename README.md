# 開示やるもんっ

インターネットで嫌なことがあったとき、泣き寝入りする前にできることがある。

まずは記録すること。
そして、自分の権利を知ること。

開示やる子は、そんなあなたの最初の一歩をお手伝いする女の子です。

Xで気になる投稿とスクショを集めて、投稿と紐づけて残すだけの、シンプルな証拠集めアプリです。
マスコットは「開示 やる子」。あつめるだけなら、かんたんっ！

## ダウンロード

最新の APK は [Releases ページ](https://github.com/ma-kun-hub/kaiji-yarumon/releases) からダウンロードできます。

- Android 専用です
- インストール時に「提供元不明のアプリ」の許可が必要な場合があります

## 特長

- **権限ゼロ・完全オフライン** — データは端末の中だけに保存されます。サーバーに送ることはありません
- **広告なし・課金なし**
- 投稿は「投稿1・2…」、スクショは「画像1・2…」、文章の証拠は「テキスト1・2…」と、並んだ順に自動で名前がつきます
- 投稿とスクショの紐づけは任意です（付け外しはいつでも自由）
- 投稿のリンクを共有すると、対象アカウントに自動で振り分けられます
- **書き出し** — 対象アカウントの投稿と証拠を全部まとめて ZIP で書き出せます（まとめ.txt とスクショ入り）。送り先は共有画面で自分で選びます

## 使い方

1. Xで気になる投稿を見つけたら、スクショを撮る
2. その投稿の共有ボタンを押して「開示やるもんっ」を選ぶ（対象アカウントに自動で保存される）
3. スクショも同じように共有するか、アプリの「証拠」から追加する
4. スクショと投稿を「紐づける・外す」ボタンで紐付けよう！ 証拠のカードのボタンから、そのスクショがどの投稿のものか選んでね。つながると投稿のところにスクショが出るよ（URLが同じものは自動でもつながる）。外すこともできるよ
5. 名前は並んだ順に自動でつくよ。投稿は「投稿1・2…」、スクショは「画像1・2…」、文章の証拠は「テキスト1・2…」。追加したり削除したりすると、その順番で付け直される
6. 集めた証拠は、投稿か証拠のページの「書き出す」から、投稿と証拠を全部まとめてZIPで取り出せるよ。中にまとめ.txt とスクショが入ってるよ。送り先は共有画面で自分で選んでね
7. （注意）共有では投稿の本文は届かないので、本文はスクショで残してね。必要なら、投稿の「編集」から書き足すこともできるよ

## Q＆A

**Q1. 個人情報は大丈夫ですか？**
はい。このアプリはインターネットに接続する権限を持っていないので、集めた投稿やスクショが外に送られることはありません。データはあなたの端末の中だけに保存されます。誰かに送るときも、「書き出す」で作ったZIPを、共有画面で自分で選んだ相手に送るだけです。

**Q2. 無料ですか？**
完全無料です。広告も課金もありません。

**Q3. 相手にバレませんか？**
バレません。アプリがXに何かを送ったり、相手に通知したりすることはありません。スクショと共有は、Xのふだんの機能を使うだけです。

**Q4. iPhoneでも使えますか？**
今はAndroid専用です。iPhone版は、評判が集まってきたらクラウドファンディングで作る計画です。

**Q5. 投稿の本文が入っていません**
Xの共有では、届くのは投稿のリンクだけです（本文は届かない仕様です）。本文はスクショで残してください。必要なときは、投稿の「編集」から本文を書き足せます。

**Q6. スクショと投稿がつながりません**
リンク（URL）が同じスクショは自動でつながります。つながらないときは、証拠のカードの「投稿と紐づける・外す」ボタンから手動でつなげます。外すこともできます。

**Q7. 機種変更のとき、データは移せますか？**
「書き出す」でZIPにして、新しい端末やパソコンに送って保管できます。ただし、アプリに読み込み直す（復元する）機能は今のところありません。ZIPは保管と送付のためのものです。

**Q8. 集めたら、本当に開示請求できますか？**
このアプリは「証拠を集める」ところまでの道具です。実際の開示請求は裁判所への申立てという手続きになります。集めたZIPは、その準備や相談にそのまま使えます。迷ったら弁護士さんに相談してみてください。

**Q9. データを全部消したいときは？**
投稿や証拠は1件ずつ削除できます。アプリをアンインストールすれば、端末内のデータは全部消えます。
